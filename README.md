# nexus-mods-helper

Adds a **Mod Info** button to Nexus Mods pages. It copies a tab-separated row
ready to paste into Google Sheets:

- Name
- Description / Notes (blank for manual entry)
- Version Tested
- Link
- Author (linked to their Nexus profile)

The tested game version defaults to `7.03.1`. Change it from your userscript
manager's **Set tested game version** menu command; the setting is retained for
future entries.

## Install

Click [here](https://github.com/SavageCore/nexus-mods-helper/releases/latest/download/nexus-mods-helper.user.js) to install with [Greasemonkey](https://www.greasespot.net/) or [Violentmonkey](https://violentmonkey.github.io/)
